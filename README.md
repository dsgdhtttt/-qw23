# 旧物回收项目全套开源系统

源码地址：ym7k.com/20061/

再生资源回收行业持续发展，传统线下回收模式存在接单混乱、价格不透明、回收员调度难、货品台账不清、对账繁琐等痛点。这套旧物回收全套开源系统，围绕回收品类管理、用户预约下单、智能派单调度、现场称重结算、分拣仓储、财务提成、数据统计打造完整业务闭环，支持私有化部署，可按需二次开发，适合社区回收服务商、旧衣废纸回收企业、家电大件回收商家、再生资源站点使用，大幅降低自主开发成本。

品类与价格管理是系统的基础模块。管理员后台统一维护回收品类，覆盖废纸、塑料、金属、旧衣物、旧家电、大件家具等，区分可回收品类与拒收品类。支持按区域动态调价，能够根据市场行情实时更新单价，不同片区、不同时段设置差异化价格。系统可以配置上门起收门槛、大件附加搬运费，同时对货品进行标签分类，便于后续分拣归类。所有价格对外公示，用户下单前即可查看，减少交易争议。

预约下单与订单追踪是面向居民用户的核心功能。用户在前端小程序或 H5 页面一键发起回收预约，自动定位所在地址，选择回收品类、预估重量，挑选合适的上门时段，还可以上传物品照片，方便回收员提前判断。订单提交后进入调度池，用户可以实时查看订单状态，了解回收员接单、出发、上门进度，支持随时取消订单。个人中心集中存放历史订单、余额明细、提现记录，同时记录累计回收重量与碳减排数据，增强用户参与环保的获得感。

智能派单与回收员移动端调度，是提升运营效率的关键。系统支持两种接单模式，平台自动派单和回收员自主抢单，结合距离、片区围栏、回收员负载情况、顺路路线进行智能分配，减少空跑。回收员移动端接收订单，内置导航功能，到达现场后可连接蓝牙电子秤，称重数据自动同步到系统，自动计算回收金额，避免人工改数带来的纠纷。交易完成后用户线上确认，钱款直接进入用户余额，回收员可以上传现场照片留存凭证，同时查看自己当日接单量、提成收入。

仓储分拣与货品流转模块，实现旧物全链路追溯。回收员完成上门回收后，将货品运送至分拣中心，仓管人员在系统登记入库，按品类、批次入库建档，记录来源、重量、入库时间。货品出库对接上游加工厂，登记出库台账，形成从居民上门、中转站入库、分拣打包、外销出库的完整流转记录。每一批货品全程留痕，方便盘点库存，防止货品丢失、账实不符。

财务结算、提成管理与售后工单支撑商业化运营。系统支持用户余额提现，后台审核提现申请，资金流水全部存档。回收员提成规则可自定义，按品类、重量设置提成比例，自动核算业绩，支持日结、周结、月结。平台统一管理投诉、售后工单，遇到重量争议、服务纠纷时在线登记处理，记录沟通结果。同时支持积分体系，用户回收旧物获得积分，可兑换生活用品、优惠券，提升用户复购意愿。

权限管控、审核与数据看板保障平台稳定运营。系统划分多级角色权限，平台管理员、片区调度员、仓管、回收员各司其职，权限相互隔离。数据看板直观展示每日订单量、回收总重量、各品类占比、热门小区、营收数据、回收员业绩排行，运营人员依托数据调整定价、优化运力布局。系统还支持营销活动配置，如新用户补贴、组团预约优惠，助力社区拓客。

除此之外，系统预留扩展接口，可对接智能回收柜、二手闲置交易、公益捐赠模块，设备满溢自动告警。整套系统聚焦上门回收业务，打通居民下单、运力调度、现场结算、仓储出库全流程，兼顾便民服务与企业管理需求，适合中小型再生资源回收服务商快速搭建线上回收平台。
